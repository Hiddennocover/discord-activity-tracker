## ❓ FAQ

**Is it safe to use?**
Yes — it's a passive tracking tool. It reads local data and does not inject code into Discord.

**Does it automatically complete quests?**
No, it's a tracker. You still need to perform the activities (watch, play, etc.) to make progress.

**Does it work on Mac or Linux?**
Currently, the tool is optimized for Windows 10/11.

**Can I get banned?**
Since it's a tracker, the risk is minimal. However, always use third-party tools at your own discretion.
